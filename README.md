# Pedido de namoro

Página React com um pedido de namoro interativo. O botão “Não” foge quando alguém tenta alcançá-lo; “Sim” abre a mensagem de comemoração com fogos de artifício.

## Rodar localmente

```bash
npm install
npm run dev
```

Para gerar a versão de produção:

```bash
npm run build
```
